Selection of Featured Used Cars

This project is a Decision Support System (DSS) designed to assist users in selecting the best and most suitable used car based on multiple criteria. The system applies the MOORA (Multi-Objective Optimization by Ratio Analysis) method, one of the most popular and effective multi-criteria decision-making techniques.

The purpose of this project is to simplify the decision-making process when choosing a used car, where buyers often face difficulties comparing specifications, conditions, and prices. With MOORA, the system objectively evaluates each car alternative based on weighted criteria and produces a final ranking recommendation.

Main Features:

  • Multi-criteria evaluation: Each car is assessed based on several criteria such as price, year of manufacture, mileage, engine performance, interior condition, and fuel efficiency.
  • Automatic data normalization: All criteria values are normalized to ensure fair comparison.
  • Dynamic weighting: Each criterion is given a weight based on its importance in decision making.
  • MOORA calculation engine: The system calculates the value of each alternative using the MOORA formula (maximization + minimization).
  • Ranking & Recommendation: Results are sorted from highest to lowest score, recommending the most suitable used car.
  • User-friendly interface: Data is displayed clearly with tables, charts, and final decision summaries.

Benefits:

  • Provides faster and more accurate decision-making.
  • Objective evaluation using scientific methods.
  • Helps buyers compare used cars more confidently.
  • Reduces risk of choosing the wrong vehicle.
  • Supports transparency by showing how each decision score is calculated.

This project highlights the effectiveness of decision-making algorithms in real-world applications. The MOORA method ensures that the selection of used cars becomes more systematic, measurable, and reliable.
